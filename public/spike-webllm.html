WebGPU in-browser LLM spike

Loads a small instruction model straight into this browser tab — either via WebLLM (Llama/Qwen, MLC's compiled q4f16 builds) or, for Gemma 4 E2B/E4B specifically, via transformers.js running the official ONNX build on WebGPU (WebLLM's mlc-llm compiler doesn't support the Gemma 4 architecture yet) — and runs it side-by-side against the app's existing server-side Ollama narration endpoint on the exact same prompts, so you can judge speed and quality directly.
